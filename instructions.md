🛠️ Vibe Coding Workflow (The "Loop")
Phase 1 (The Foundation): The Architect generates the skeleton. You review and say, "Looks good, let's add the UI."

Phase 2 (The Visuals): The Artisan builds the screens based on the UI prompt we created earlier. You vibe-check the colors and responsiveness.

Phase 3 (The Intelligence): The Brain writes the logic for image processing and the email lookup system.

Phase 4 (The Glue): The Closer joins the pieces. You run a test: "Report a pothole in Ujjain," and the agent ensures the whole flow works from camera to email.
